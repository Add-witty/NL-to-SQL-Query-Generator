## Documentation

Keep the project documentation synchronized with the implementation.

When completing a task:

1. Determine whether an architectural or design decision was made.
2. If yes, update `DECISIONS.md` automatically before finishing the task.
3. If no, explicitly state:
   - "No update to DECISIONS.md required."

Only record decisions that affect:

- Architecture
- Data models
- Public interfaces
- Technology choices
- Development workflow

Do not record:

- Bug fixes
- Refactoring
- Formatting
- Tests
- Temporary workarounds
- Implementation details
