Project Scope

The application will:

✔ Accept natural language

✔ Accept uploaded CSV files

✔ Accept uploaded Excel files

✔ Accept SQL schema files

✔ Accept SQLite databases

✔ Extract schema automatically

✔ Generate SQL

The application will NOT:

✘ Execute SQL

✘ Modify databases

✘ Perform INSERT/UPDATE/DELETE

✘ Train custom models

✘ No authentication. 

✘ No login page. 

✘ No dashboard. 

✘ No payment. 

✘ No user information. 

✘ No cloud deployment.
